# تاسك المشروع 14: Task 7 — Coffee Order Form

أخذ بيانات من المستخدم، التحقق منها (validation)، تطبيق قواعد عمل بسيطة، ثم عرض الطلب على الصفحة.

الملفات:

- `index.html`
- `style.css`
- `app.js` (مربوط بـ `defer`)
- `screenshot.jpg` ← صورة الصفحة شغّالة

## الصفحة

- حقول الفورم: **Name**، **Phone**، **Product** (قائمة منسدلة)، **Quantity**
- زر **Order**
- منطقة فاضية تحت الفورم لعرض الطلب

## المنتجات

| المنتج | السعر |
| --- | --- |
| Espresso | 45 EGP |
| Latte | 65 EGP |
| Croissant | 40 EGP |

## التحقق (Validation)

- [ ] الاسم مطلوب و**3 أحرف على الأقل**
- [ ] الهاتف **11 رقم ويبدأ بـ 01** → باستخدام **regex**: `/^01\d{9}$/`
- [ ] لازم اختيار منتج
- [ ] الكمية من **1 إلى 10**
- [ ] رسالة الخطأ تظهر **تحت الحقل** نفسه
- [ ] وجود أي خطأ → **ما بينعرض الطلب**

## قواعد العمل (Business Rules)

- `Total = price × quantity`
- كمية **3 أو أكثر** → خصم **10%**
- المجموع **فوق 200 EGP** → إظهار **Free delivery**

## عرض الطلب

```
Name: Sara
Product: Latte × 3
Total: 175.5 EGP
```

وتفريغ الفورم بعد العرض.

### Bonus ✅

كل طلب جديد بينضاف **تحت** الطلب السابق بدل ما يستبدله.

## افتراضات

1. شرط **Free delivery** محسوب على المجموع **بعد الخصم** (أي المجموع النهائي المعروض).
2. تنسيق المبلغ زي مثال التاسك: `175.5` مش `175.50`.
3. كل الأحداث عبر `addEventListener` وبدون `onclick` داخل HTML.

## نتائج الاختبار (تم التجريب على المتصفح)

| الحالة | الناتج |
| --- | --- |
| اسم `Sa` + هاتف `0123` + بدون منتج + كمية `0` | أربع رسائل خطأ تحت الحقول، وما انعرض أي طلب |
| `Sara` + `01012345678` + Latte + 3 | `Total: 175.5 EGP` (195 ناقص 10%) والفورم انفرغ |
| `Hamza` + Espresso + 5 | `Total: 202.5 EGP` + شارة **Free delivery**، وانضاف **تحت** الطلب الأول |
| كمية `11` | `Quantity must be from 1 to 10` وعدد الطلبات ما زاد |

## طريقة التشغيل

افتح `index.html` بالمتصفح.
