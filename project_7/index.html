Layout & UI

I like taking a static design, cutting it into sections, and sitting with Flexbox or Grid until the page matches what I saw on screen. Spacing, type size, the last 10px: that's usually what makes it look finished.

I'm studying Computer Science at Université Hassan II in Casablanca. The lectures cover the theory; the weekly front-end tasks are where I actually learned to structure a page and style it without guessing.

This portfolio is a front-end practice project created with HTML and CSS only. No JavaScript, no framework — just the layout techniques from class, used on one page.
