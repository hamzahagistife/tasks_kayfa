### What I learned

The hard shadow was the main thing here — not a blurry box-shadow, just a solid offset so the card looks like a sticker. Also made the title a link and switched its color to yellow on hover.

```css
.card {
  border: 1px solid var(--gray-950);
  box-shadow: 8px 8px 0 var(--gray-950);
}
```

Used the local Figtree files instead of Google Fonts so it matches the rest of my Frontend Mentor folders.
