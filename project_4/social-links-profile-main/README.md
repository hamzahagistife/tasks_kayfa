### What I learned

Pretty straightforward card layout. The hover on the links looks nicer when both the background and text color swap — green bg with dark text instead of just tinting the button.

```css
.links a:hover {
  background-color: var(--green);
  color: var(--grey-900);
}
```

Used the local Inter font files again so everything stays offline-friendly.
