# تاسك المشروع 11: JS Task 3 — Analyze Range

التاسك التالت في سلسلة الجافاسكربت. تمرين على: **الدوال (functions)**، `return`،
حلقة `for`، العدّادات (counters) والمجمّعات (accumulators)، وباقي القسمة `%`.

## الهدف

بناء دالة بتحلّل مجال من الأرقام وبترجع ملخّص واضح كنص.

الملفات المطلوبة:

- `index.html`
- `app.js` (مربوط بـ `defer`)

## الدالة المطلوبة

```js
analyzeRange(start, end)
```

### المتطلبات

- [ ] إذا كان `start` أكبر من `end` → ترجع `"Invalid range"`
- [ ] حلقة من `start` إلى `end` **شاملة الطرفين**
- [ ] عدّ الأرقام الزوجية
- [ ] عدّ الأرقام الفردية
- [ ] حساب مجموع الأرقام الزوجية
- [ ] حساب مجموع كل الأرقام
- [ ] إرجاع **نص ملخّص واحد واضح**
- [ ] استخدام حلقة `for`
- [ ] أسماء متغيرات معبّرة
- [ ] استخدام counters و accumulators
- [ ] استخدام `return` — **ممنوع** الطباعة فقط من جوّا الدالة

بعدين: تخزين القيمة المُرجَعة في متغير، ثم طباعته.

## Bonus

```js
countMultiples(start, end, divisor)
```

بترجع **كم رقم** في المجال يقبل القسمة على `divisor` بدون باقي.

## النتيجة المتوقعة

```
analyzeRange(1, 10)   -> even: 5 (sum 30) , odd: 5 , total sum: 55
analyzeRange(10, 1)   -> "Invalid range"
countMultiples(1, 20, 3) -> 6   // 3,6,9,12,15,18
```

## معيار الإنجاز

- [ ] الدالة بترجع نص ولا تطبع من الداخل
- [ ] الحالة الخاطئة (`start > end`) متعالجة
- [ ] الحلقة شاملة `start` و `end`
- [ ] كل الأرقام محسوبة بالعدّادات لا يدوياً
- [ ] الدالة الإضافية `countMultiples` شغّالة

## طريقة التشغيل

افتح `index.html` بالمتصفح ثم `F12` → تبويب **Console**.
