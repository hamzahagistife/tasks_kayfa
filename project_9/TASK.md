# تاسك المشروع 9: Task 1 — Book Order Receipt (JavaScript)

أول تاسك في سلسلة تاسكات الجافاسكربت. الهدف تمرين على: المتغيرات، `const` و `let`،
الأنواع (types)، التحويل بين النصوص والأرقام، العمليات الحسابية، و Template Literals.

## الهدف

طباعة **فاتورة طلب كتاب** في الـ Console بدون أي HTML ديناميكي — كل الشغل في `app.js`.

الملفات المطلوبة:

- `index.html`
- `app.js`

## التقنيات والقيود

- JavaScript فقط (بدون مكتبات وبدون سيرفر)
- ربط ملف الجافاسكربت بالـ HTML باستخدام **`defer`**
- البيانات مكتوبة مباشرة داخل `app.js` (لا يوجد إدخال من المستخدم)
- الناتج يظهر في **Console** المتصفح فقط
- ممنوع كتابة النتائج المحسوبة يدوياً في الكود — لازم تنحسب بالعمليات

## البيانات

| القيمة | المحتوى | ملاحظة |
| --- | --- | --- |
| اسم الزبون | `" Sara "` | مع مسافات في البداية والنهاية |
| اسم الكتاب | `"JavaScript Basics"` | |
| سعر الكتاب الواحد | `150` | رقم |
| الكمية المُدخلة | `"3"` | **نص** ويبقى نص كما هو |
| تكلفة الشحن | `30` | رقم |

## المطلوب بالتفصيل

1. أسماء متغيرات واضحة ومعبّرة، واختيار `const` أو `let` حسب إذا كان المتغير رح يُعاد تعيينه.
   (هنا ما في أي إعادة تعيين → كلها `const`.)
2. إنشاء اسم زبون **بدون مسافات** في البداية والنهاية، مع طباعة الاسم الأصلي والاسم المنظّف
   بطريقة تخلّي المسافات **ظاهرة** (مثلاً بين أقواس `[ ]`).
3. إنشاء كمية **رقمية** من الكمية النصية، وطباعة **القيمة والنوع** للاثنتين
   (النصية والرقمية) باستخدام `typeof`.
4. حساب الـ **subtotal** = سعر الكتاب × الكمية (قبل الشحن).
5. حساب الـ **total** = subtotal + الشحن.
6. قبل التشغيل: كتابة النتيجة المتوقعة للـ subtotal والـ total في **تعليقات**.
7. طباعة فاتورة باستخدام **Template Literal** تحتوي على:
   الاسم المنظّف، اسم الكتاب، سعر الوحدة، الكمية، subtotal، الشحن، total —
   مع إظهار المبالغ بـ **خانتين عشريتين** (`toFixed(2)`).

## النتيجة المتوقعة

```
subtotal = 150 × 3 = 450.00
total    = 450 + 30 = 480.00
```

## معيار الإنجاز

- [ ] الملفان `index.html` و `app.js` موجودان والربط بـ `defer`
- [ ] كل البيانات داخل `app.js`
- [ ] المسافات في الاسم الأصلي ظاهرة عند الطباعة، والاسم المنظّف بدون مسافات
- [ ] طباعة القيمة والنوع للكمية النصية والكمية الرقمية
- [ ] `subtotal` و `total` محسوبان بالكود لا مكتوبان يدوياً
- [ ] التعليقات فيها النتيجة المتوقعة قبل التشغيل
- [ ] الفاتورة مطبوعة بـ Template Literal والمبالغ بخانتين عشريتين
