# تاسك المشروع 12: JS Task 4 — Products, Set, Object, Map & Cart Total

التاسك الرابع. تمرين على: **المصفوفات (Array)**، **الكائنات (Object)** والكائنات المتداخلة،
**Set**، **Map**، والحلقات على هياكل البيانات، ودالة بترجع نتيجة.

الملفات المطلوبة:

- `index.html`
- `app.js` (مربوط بـ `defer`)

## 1) Products

إنشاء مصفوفة اسمها `products` فيها **5 منتجات على الأقل** ككائنات.
كل منتج لازم يحتوي:

- `id`
- `name`
- `category`
- `price`
- `inStock`

بقيم مختلفة.

## 2) Product List

طباعة:

- [ ] اسم أول منتج
- [ ] اسم آخر منتج
- [ ] عدد المنتجات

ثم المرور على كل المنتجات وطباعة **سطر لكل منتج**.

## 3) Selected Filters

إنشاء **Set** اسمها `selectedCategories`:

- [ ] إضافة 3 تصنيفات على الأقل
- [ ] محاولة إضافة تصنيف **مرتين** (لملاحظة إن الـ Set ما بتقبل التكرار)
- [ ] طباعة الـ Set، وحجمها (`size`)، وهل تصنيف معيّن مُختار (`has`)

## 4) Current User

إنشاء كائن واحد اسمه `currentUser` يحتوي:

- `id`
- `name`
- `email`
- `address` ← لازم يكون **كائن متداخل (nested object)**

ثم **قراءة المدينة** من الكائن المتداخل.

## 5) Shopping Cart Quantities

إنشاء **Map** اسمها `cartQuantity`:

- المفاتيح = `id` المنتجات
- القيم = الكميات
- [ ] 3 عناصر على الأقل
- [ ] طباعة الكمية لمنتج معيّن (`get`)
- [ ] طباعة هل منتج آخر موجود (`has`)
- [ ] طباعة حجم الـ Map (`size`)

## 6) Cart Total

```js
calculateCartTotal(products, cartQuantity)
```

المتطلبات:

- [ ] المرور على `products`
- [ ] جلب الكمية من الـ Map باستخدام `id` المنتج
- [ ] إذا المنتج مش موجود بالـ Map → الكمية = **0**
- [ ] جمع `price * quantity`
- [ ] إرجاع المجموع النهائي (`return`)

## البيانات المستخدمة والنتيجة المتوقعة

| id | name | category | price | inStock | الكمية بالسلة |
| --- | --- | --- | --- | --- | --- |
| 1 | Laptop | electronics | 1200 | true | 1 |
| 2 | Headphones | electronics | 150 | true | 2 |
| 3 | Coffee Mug | kitchen | 25 | false | — |

| 5 | Notebook | stationery | 12 | true | — |

```
total = (1200 × 1) + (150 × 2) + (60 × 3) = 1200 + 300 + 180 = 1680
```

- الـ Set: 3 تصنيفات رغم إضافة واحد مرتين → `size = 3`

## معيار الإنجاز

- [ ] 5 منتجات بكل الحقول المطلوبة
- [ ] طباعة أول منتج وآخر منتج والعدد + سطر لكل منتج
- [ ] Set مع محاولة تكرار + طباعة الحجم و `has`
- [ ] كائن متداخل وقراءة المدينة منه
- [ ] Map مع `get` و `has` و `size`
- [ ] `calculateCartTotal` بترجع المجموع ومعالجة المنتجات غير الموجودة بالسلة
