# تاسك المشروع 13: Task 6 — Find the Secret Number

لعبة بسيطة بالمتصفح باستخدام **DOM و Events**. اللاعب بيحزر رقم سري من 1 إلى 10.

الملفات:

- `index.html`
- `style.css`
- `app.js` (مربوط بـ `defer`)
- `screenshot.jpg` ← صورة اللعبة شغّالة (حالة الفوز)

## 1) الصفحة

- [ ] عنوان اللعبة
- [ ] حقل إدخال رقمي واحد
- [ ] زر **Check**
- [ ] منطقة رسالة
- [ ] عدّاد محاولات
- [ ] زر **Reset**

## 2) حالة اللعبة

```js
const secretNumber = 7;   // النسخة الأساسية
let attempts = 5;
```

- الرقم السري **ما بينعرض** بالصفحة
- عدد المحاولات الابتدائي بيبان بالواجهة

> في هذا المشروع تم تطبيق **Bonus 1**، فصار `let secretNumber = createSecretNumber();`
> والتعليق داخل `app.js` بيوضّح النسخة الأساسية.

## 3) فحص التخمين

عند الضغط على **Check**: قراءة القيمة، تحويلها لرقم، ثم:

| الحالة | الرسالة |
| --- | --- |
| الحقل فاضي | `Enter a number` |
| رقم أقل من 1 أو أكبر من 10 | `Choose a number from 1 to 10` |
| الرقم صحيح | `Correct!` |
| تخمين أعلى من السري | `Too high` + نقص محاولة |
| تخمين أقل من السري | `Too low` + نقص محاولة |

تحديث عدد المحاولات في الـ DOM بعد كل تخمين خاطئ.

## 4) حالة الفوز

- `Correct!`
- إضافة **class** اسمه `win` بيغيّر شكل صندوق اللعبة
- تعطيل زر Check

⚠️ الستايل كله بالـ CSS — الجافاسكربت بس بتضيف الكلاس (ممنوع تغيير عدّة ستايلات مباشرة من JS).

## 5) حالة الخسارة

لما المحاولات توصل 0:

- `Game over`
- تعطيل زر Check
- إضافة class اسمه `lose`

## 6) إعادة اللعبة

دالة باسم `resetGame` تُمرَّر لـ `addEventListener`:

- [ ] المحاولات ترجع 5
- [ ] تحديث العدّاد بالـ DOM
- [ ] تفريغ حقل الإدخال
- [ ] تصفير الرسالة
- [ ] تفعيل زر Check
- [ ] إزالة كلاسات `win` و `lose`

